# Conformal_Biomedical_LLM
Zero-shot LLM classification of biomedical abstracts (Qwen2.5 3B/7B): systematic overconfidence, temperature scaling and conformal prediction (LAC, APS, class-conditional). A 90% marginal guarantee holds on average but leaves one class below 85% coverage in 90-96% of 500 re-splits; class-conditional calibration fixes it.
